# Old core phrases (mastered)

Phrases I can now say without thinking, moved out of the active [core-phrases.md](../current/core-phrases.md).
Nothing here yet — tell me "this one's familiar now" and I'll move it here.

| Phrase | When to use it |
|---|---|
| "I think this needs to be fixed." | flagging a bug |
| "Could you take a look?" | asking someone to check something |
| "I left a few comments." | with feedback |
| "Looks good to me." | approving |
| "How big is it?" | asking about scale |
| "Can you review my PR when you get a chance?" | asking for a review |
| "Have a look when you get a chance." | after leaving comments; no rush |
| "I fixed all the comments — could you take another look?" | asking for a re-review after fixes |
| "Sorry, can you say that again?" | when you didn't catch something |
| "I get that, but I think we should wait." | disagreeing politely |
| "Could you let the team know once the demo is done? Then we can start merging our PRs into dev." | asking the lead to signal when it's clear to proceed |
| "Here's the ticket we mentioned in the meeting about the deployment slots: [link]" | sharing a ticket you talked about in a meeting |
| "Could you tell me anything that doesn't sound natural?" | asking for feedback on your English |
| "How did the demo go? Any feedback we should know about?" | asking how something went that you missed |
